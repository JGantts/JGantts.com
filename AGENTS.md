# Codebase map

JGantts.com combines a Vue site, an Express content server, and an offline map pipeline.
Start with the area you need; each map links to focused component notes and source files.

- [Website](docs/architecture/website/index.md): routes, layouts, photo browsing, and private authoring in `jgantts-com`.
- [Content server](docs/architecture/server/index.md): HTTP delivery, posts, media, persistence, and social integrations in `jgantts-server`.
- [Kovyálo maps](docs/architecture/maps/index.md): interactive maps, region configuration, and Python asset generation.
- [Operations](docs/architecture/operations/index.md): development checks, release deployment, and recovery.

Existing `docs/*-ROADMAP.md` files track plans and history; the architecture tree describes current source behavior.
